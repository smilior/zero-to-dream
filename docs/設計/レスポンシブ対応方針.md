# レスポンシブ対応方針

## 概要

シンプル ToDo アプリのデバイス別対応方針を定義する。
UI 実装時のブレを防ぎ、対応範囲を明確にする。

## 対応デバイス

| デバイス | 対応 | 理由 |
|---|---|---|
| PC（デスクトップ / ラップトップ） | ✅ 対応 | 主要利用環境。企画書の要件 |
| タブレット | — 対象外 | 今回のスコープ外 |
| スマートフォン | — 対象外 | 今回のスコープ外 |

## 対応画面幅

| ブレークポイント | 画面幅 | 対応方針 |
|---|---|---|
| PC | 1024px 以上 | レイアウトを最適化して表示する |
| タブレット以下 | 1023px 以下 | 動作は保証しない（スコープ外） |

## レイアウト方針

### PC（1024px 以上）

- コンテンツ幅は中央寄せ・最大幅 `max-w-2xl`（Tailwind CSS）程度に制限
- 1 カラム縦積みレイアウト（検索 → 入力フォーム → タスクリスト）
- タスクリストの各行は横並び（チェック / タスク名 / 期限 / 削除ボタン）

```
┌──────────────────────────────┐
│         シンプル ToDo         │
│  ┌──────────────────────┐   │
│  │ 🔍 検索...            │   │
│  └──────────────────────┘   │
│  ┌────────────┐ ┌──┐ ┌──┐  │
│  │ タスク名入力 │ │日付│ │追加│  │
│  └────────────┘ └──┘ └──┘  │
│  ────────────────────────   │
│  ☐  タスク名    2026/06/30 🗑 │
│  ✅  タスク名    ──         🗑 │
└──────────────────────────────┘
```

## Tailwind CSS のブレークポイント運用

| Tailwind prefix | 画面幅 | 今回の使用 |
|---|---|---|
| （なし / デフォルト） | 全幅 | ベーススタイル（PC 向けに設計） |
| `sm:` | 640px 以上 | 使用しない |
| `md:` | 768px 以上 | 使用しない |
| `lg:` | 1024px 以上 | 必要に応じて使用 |

今回は PC のみを対象とするため、レスポンシブプレフィックスは最小限に留める。
デフォルトスタイルを PC 向けに設計し、モバイル対応は行わない。

## 今後の対応について

スマートフォン・タブレット対応が必要になった場合は、以下を検討する。

- Tailwind CSS のブレークポイントを活用したレスポンシブ対応
- モバイルファーストへのレイアウト変更
