# システム構成

## 概要

シンプル ToDo アプリのシステム全体構成を定義する。
アプリ・DB・インフラの関係を明確にし、設計・実装の基準とする。

## 構成図

```
┌─────────────────────────────────────────┐
│  ブラウザ（PC）                           │
│  HTML + Tailwind CSS + Alpine.js         │
│  ※ CDN 読み込み                          │
└────────────────┬────────────────────────┘
                 │ HTTP（REST API）
                 ▼
┌─────────────────────────────────────────┐
│  バックエンド                             │
│  FastAPI（Python）                       │
│  - タスクの CRUD API を提供              │
│  - 静的ファイル（HTML）の配信            │
└────────────────┬────────────────────────┘
                 │ sqlite3（Python 標準ライブラリ）
                 ▼
┌─────────────────────────────────────────┐
│  データベース                             │
│  SQLite（ファイルベース）                 │
│  todos.db                               │
└─────────────────────────────────────────┘
```

## コンポーネント詳細

### フロントエンド

| 項目 | 内容 |
|---|---|
| 構成 | 単一 HTML ファイル |
| スタイリング | Tailwind CSS（CDN） |
| 動的処理 | Alpine.js（CDN） |
| 通信 | Alpine.js から FastAPI へ fetch で REST API 呼び出し |

### バックエンド

| 項目 | 内容 |
|---|---|
| フレームワーク | FastAPI（Python） |
| 役割 | REST API の提供 ＋ HTML ファイルの配信 |
| 起動 | `uvicorn` で起動 |
| ポート | 8000（開発環境） |

### データベース

| 項目 | 内容 |
|---|---|
| DB | SQLite |
| ファイル | `todos.db`（app/ 直下） |
| アクセス | Python 標準ライブラリ `sqlite3` |

## API エンドポイント（概要）

| メソッド | パス | 処理 |
|---|---|---|
| GET | `/api/todos` | タスク一覧取得（検索クエリ対応） |
| POST | `/api/todos` | タスク追加 |
| PATCH | `/api/todos/{id}` | タスク更新（完了切り替えなど） |
| DELETE | `/api/todos/{id}` | タスク削除 |
| GET | `/` | HTML ファイル配信 |

## デプロイ構成

ローカル環境での個人利用のみ想定。クラウドデプロイは今回のスコープ外。

```
開発 / 本番: ローカルマシン上で uvicorn を起動して使用
```
