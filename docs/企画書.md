# シンプル ToDo 企画書

## 概要
- 名称: シンプル ToDo（仮）
- 形態: Web アプリケーション（PC のブラウザで動作）
- 目的: 日々のタスクを登録・管理する、最小限の ToDo アプリ
- 利用者: 個人が自分のタスク管理に使う

## 今回作る機能（最小限）
1. タスクを追加する
2. タスクの一覧を表示する
3. タスクの完了 / 未完了を切り替える
4. タスクを削除する
5. タスクに期限を設定する
6. タスクを検索する
7. タスクを SQLite に保存する（再アクセスしても内容が残る）

## 今回は作らない機能（スコープ外）
- ユーザー認証・ログイン
- 優先度 / カテゴリ / 並べ替え
- 複数ユーザーでの共有（今回は個人利用のみ）
- 通知
- テスト（テスト以降はスコープ外）

## 画面
- 1 画面のみ
  - タスクの入力欄 ＋「追加」ボタン
  - タスクの一覧（各行に 完了チェック / 削除）

## 動作環境・技術
- PC のブラウザで動作する Web アプリ
- バックエンド: FastAPI（Python）
- フロントエンド: Tailwind CSS ＋ Alpine.js（CDN 読み込み）
- データの保存: SQLite（Python 標準の sqlite3）
- 構成はシンプルに保つ（詳細は設計で確定する）
