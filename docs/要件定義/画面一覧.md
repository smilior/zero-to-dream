# 画面一覧と画面遷移図

## 概要

シンプル ToDo アプリの画面構成を定義する。
今回は 1 画面のみで完結する構成とする。

## 画面一覧

| # | 画面名 | パス | 概要 |
|---|---|---|---|
| S-01 | ToDo メイン画面 | `/` | タスクの追加・一覧・操作をすべて行う唯一の画面 |

## 画面遷移図

画面が 1 つのみのため、遷移は発生しない。
すべての操作（追加・完了切り替え・削除・検索）は同一画面内でインタラクティブに処理される。

```
[ブラウザで / にアクセス]
         │
         ▼
┌─────────────────────┐
│  ToDo メイン画面     │  ← すべての操作がここで完結
│                     │
│  [検索欄]           │
│  [入力欄] [日付] [追加] │
│  ─────────────────  │
│  ☐ タスク名  期限  🗑 │
│  ☐ タスク名  期限  🗑 │
│  ✅ タスク名  期限  🗑 │
└─────────────────────┘
```

## S-01: ToDo メイン画面 — 画面要素詳細

### ヘッダーエリア

| 要素 | 内容 |
|---|---|
| アプリ名 | 「シンプル ToDo」などのタイトルテキスト |

### 検索 ＋ 並べ替えエリア

| 要素 | 内容 |
|---|---|
| 検索入力欄 | タスク名をキーワードで絞り込む。入力に応じてリアルタイムでフィルタリング |
| 並べ替えセレクト | 追加順 / 期限順（早い順）/ 完了状態順（未完了を上）から選択 |

### タスク入力エリア

| 要素 | 内容 |
|---|---|
| タスク名入力欄 | タスク名をテキスト入力（必須） |
| 期限入力欄 | 日付ピッカーで期限を選択（任意） |
| 追加ボタン | 入力内容を送信してタスクをリストに追加する |

### タスクリストエリア

各タスクは 1 行で以下の要素を持つ。

| 要素 | 内容 |
|---|---|
| 完了チェックボックス | オン / オフで完了 / 未完了を切り替える |
| タスク名 | 登録時のタスク名テキスト。完了時は打ち消し線を表示 |
| 期限 | 設定された期限日を表示。未設定の場合は空白 |
| 削除ボタン | タスクをリストから即時削除する |

## 状態変化

画面遷移はないが、以下の状態変化がある。

| アクション | 変化 |
|---|---|
| タスク追加 | リストの末尾にタスクが追加される |
| 完了チェック ON | タスク名に打ち消し線が入り、完了状態になる |
| 完了チェック OFF | 打ち消し線が消え、未完了状態に戻る |
| 削除ボタン押下 | タスクがリストから消える |
| 検索キーワード入力 | キーワードに一致するタスクのみ表示される |
| 検索欄クリア | 全タスクが表示される |
