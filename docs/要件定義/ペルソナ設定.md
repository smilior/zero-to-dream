# ペルソナ設定

## 概要

このドキュメントは、シンプル ToDo アプリの代表的なユーザー像を定義する。
設計・実装の判断に迷ったときに「このユーザーにとって何が必要か」を確認するための基準として使う。

## ペルソナ

| 項目 | 内容 |
|---|---|
| **名前（仮）** | 中川さん |
| **職種** | エンジニア |
| **タスク管理の現状** | 紙のメモにタスクを書いている |
| **主な困りごと** | タスクを書いたまま忘れる。紙が散らばって後から見返せない |
| **ツール利用歴** | 専用のタスク管理ツールは使っていない |
| **利用環境** | PC のブラウザ（作業中に気軽に開ける） |

## 困りごとの詳細

### 現在の課題

- タスクを紙に書くが、後で見返す習慣がなくそのまま忘れる
- 紙は持ち運びが不便で、デスクを離れると確認できない
- 期限を意識せずタスクをこなすため、締め切りを過ぎることがある

### このアプリに求めること

- 難しい操作なしにすぐタスクを登録できる
- 一覧でタスクを把握できる（見た目がシンプルであること）
- 期限を設定しておけば、期限を忘れない
- ブラウザで開けばすぐ使える（ログイン不要）
- 再アクセスしてもタスクが残っている

## このペルソナが使わないもの

以下の機能はこのペルソナのニーズに合わないため、スコープ外とする。

| 機能 | 理由 |
|---|---|
| ユーザー認証・ログイン | 自分だけが使うため不要 |
| 他者との共有 | 個人利用のみ |
| 優先度・カテゴリ | シンプルさを優先。複雑にしたくない |
| 通知 | ブラウザで確認するだけで十分 |
