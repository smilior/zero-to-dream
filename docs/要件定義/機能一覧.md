# 機能一覧

## 概要

シンプル ToDo アプリで実装する機能を必須・オプション・スコープ外に分類する。

## 必須機能（MVP）

今回のリリースで必ず実装する機能。

| # | 機能名 | 概要 | 関連 US |
|---|---|---|---|
| F-01 | タスク追加 | タスク名と期限を入力して登録する | US-01 |
| F-02 | タスク一覧表示 | 登録済みタスクをリスト表示する | US-02 |
| F-03 | 完了 / 未完了の切り替え | チェックボックスで状態を切り替える | US-03 |
| F-04 | タスク削除 | 削除ボタンでタスクを即時削除する | US-04 |
| F-05 | 期限の設定・表示 | タスクに期限日を設定し一覧に表示する | US-05 |
| F-06 | タスク検索 | キーワードでタスク名を絞り込む | US-06 |
| F-07 | データ永続保存 | SQLite にタスクを保存する | US-07 |
| F-08 | タスクの並べ替え | 追加順 / 期限順 / 完了状態順で並べ替える | — |

## オプション機能（今回は実装しない）

将来的に追加を検討できるが、今回はスコープ外とする機能。

| # | 機能名 | 概要 | 除外理由 |
|---|---|---|---|
| F-12 | 優先度設定 | タスクに優先度（高・中・低）を付ける | 最小限の MVP に絞るため |
| F-13 | カテゴリ / タグ | タスクをカテゴリ別に分類する | 最小限の MVP に絞るため |
| F-14 | 通知 | 期限前にブラウザ通知を送る | 今回のスコープ外 |
| F-15 | ユーザー認証 | ログイン機能を追加する | 個人利用のみのため不要 |
| F-16 | 複数ユーザー共有 | チームでタスクを共有する | 個人利用のみ |

## 機能と画面要素の対応

| 機能 | 画面要素 |
|---|---|
| F-01 タスク追加 | テキスト入力欄 ＋ 日付入力欄 ＋「追加」ボタン |
| F-02 タスク一覧表示 | タスクリスト（タスク名・期限・完了チェック・削除ボタン） |
| F-03 完了 / 未完了の切り替え | 各タスク行のチェックボックス |
| F-04 タスク削除 | 各タスク行の削除ボタン |
| F-05 期限の設定・表示 | 追加フォームの日付入力欄 ／ リストの期限日テキスト |
| F-06 タスク検索 | 検索入力欄 |
| F-07 データ永続保存 | （画面要素なし。バックエンドで自動処理） |
| F-08 タスクの並べ替え | 並べ替えセレクトボックス（追加順 / 期限順 / 完了状態順） |
