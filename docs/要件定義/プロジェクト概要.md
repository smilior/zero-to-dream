# プロジェクト概要

## プロジェクト名

**シンプル ToDo**（仮）

## 目的

紙のメモで管理していたタスクをブラウザで管理できるようにする。
タスクの登録・確認・完了・削除を 1 画面でできる最小限の ToDo アプリを作る。

## 達成目標

| # | 目標 | 判定基準 |
|---|---|---|
| 1 | タスクを追加できる | タスク名と期限を入力して「追加」ボタンを押すとリストに表示される |
| 2 | タスクを一覧で確認できる | アプリを開くと登録済みのタスクが一覧表示される |
| 3 | 完了・未完了を切り替えられる | チェックボックスで状態を切り替えられる |
| 4 | タスクを削除できる | 削除ボタンを押すとリストから消える |
| 5 | 期限を設定・確認できる | タスクに期限日を設定でき、一覧に表示される |
| 6 | タスクを検索できる | 検索欄にキーワードを入れるとリストが絞り込まれる |
| 7 | データが永続する | 再アクセスしても登録済みのタスクが残っている |

## スコープ

### 対象

- 個人が自分のタスク管理に使う Web アプリ（PC ブラウザ）
- ログイン不要・1 ユーザーのみ

### 対象外

- ユーザー認証・ログイン
- 複数ユーザーでの共有
- 優先度・カテゴリ・並べ替え
- 通知
- テスト

## 技術スタック

| レイヤー | 技術 |
|---|---|
| バックエンド | FastAPI（Python） |
| フロントエンド | Tailwind CSS ＋ Alpine.js（CDN 読み込み） |
| データ保存 | SQLite（Python 標準の sqlite3） |
