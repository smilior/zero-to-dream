# ユーザーストーリーマッピング

## 概要

このドキュメントは、シンプル ToDo アプリにおけるユーザーの日常的な行動を時系列で整理し、
必要な機能とその優先順位を可視化するためのユーザーストーリーマップである。

- **バックボーン**: ユーザーが 1 日の中で行う大きな活動（左から時系列順）
- **ウォーキングスケルトン**: 各活動を構成する具体的な行動
- **ストーリー（機能）**: アプリが提供する機能
- **MVP**: 今回のリリースで実装するか否か（✅ = 実装 / — = スコープ外）

## ユーザー像

個人で日々のタスクを管理したい人。ログインや共有は不要で、自分だけがブラウザから使う。

## ユーザーストーリーマップ

| バックボーン | ウォーキングスケルトン | ストーリー（機能） | MVP |
|---|---|---|:---:|
| **① 今日やることを確認する** | アプリを開く | タスク一覧を表示する | ✅ |
| | タスクを一覧で眺める | 未完了・完了を区別して表示する | ✅ |
| | 期限を確認する | 各タスクに期限日を表示する | ✅ |
| **② 新しいタスクを登録する** | タスク名を入力する | テキスト入力欄にタスク名を入れる | ✅ |
| | 期限を設定する | 日付入力で期限を設定する | ✅ |
| | 登録する | 「追加」ボタンで保存する | ✅ |
| | （次回も残す） | SQLite に永続保存する | ✅ |
| **③ タスクをこなしながら進捗を記録する** | タスクに取り組む | — | — |
| | 完了したら記録する | 完了チェックをオンにする | ✅ |
| **④ 完了したタスクをチェックする** | 完了済みタスクを確認する | 完了タスクを一覧で見る | ✅ |
| | やっぱり戻す | 完了 → 未完了に切り替える | ✅ |
| **⑤ 期限が近いタスクを確認する** | 期限日を見る | 期限日を各タスクに表示する | ✅ |
| | 優先度を判断する | 期限順の並べ替え | — |
| **⑥ 不要なタスクを片付ける** | 削除するタスクを選ぶ | 各タスク行に削除ボタンを置く | ✅ |
| | 削除する | 削除ボタンで即時削除する | ✅ |
| **⑦ 過去に登録したタスクを探す** | キーワードで探す | 検索欄でタスク名を絞り込む | ✅ |

## MVP の範囲

### 実装する機能

| # | 機能 |
|---|---|
| 1 | タスクの一覧表示 |
| 2 | タスクの追加（タスク名 ＋ 期限） |
| 3 | 完了 / 未完了の切り替え |
| 4 | タスクの削除 |
| 5 | 期限の表示 |
| 6 | タスクの検索（タスク名の絞り込み） |
| 7 | SQLite による永続保存 |

### スコープ外

| 機能 | 理由 |
|---|---|
| 期限順の並べ替え | 個人利用では手動管理で十分。優先度機能はスコープ外 |
| ユーザー認証・ログイン | 個人利用のみのため不要 |
| 優先度 / カテゴリ | 最小限の MVP に絞るため除外 |
| 通知 | 今回のスコープ外 |
| 複数ユーザー共有 | 個人利用のみ |
