# ユーザーストーリー / ユースケース

## 概要

シンプル ToDo アプリの機能を「ユーザーとして、〇〇したい。なぜなら△△だから。」の形式で記述する。
このドキュメントは実装する機能の根拠と優先順位の基準として使う。

## ユーザーストーリー

### タスクの追加

| 項目 | 内容 |
|---|---|
| **ID** | US-01 |
| **ストーリー** | ユーザーとして、タスク名と期限を入力してタスクを追加したい。なぜなら、今やるべきことを忘れずに記録したいから。 |
| **受け入れ条件** | ・タスク名を入力して「追加」ボタンを押すとリストに追加される<br>・期限（日付）を設定できる<br>・タスク名が空の場合は追加されない |
| **MVP** | ✅ |

---

### タスクの一覧表示

| 項目 | 内容 |
|---|---|
| **ID** | US-02 |
| **ストーリー** | ユーザーとして、登録したタスクを一覧で確認したい。なぜなら、今やるべきことを把握したいから。 |
| **受け入れ条件** | ・アプリを開くと登録済みのタスクが表示される<br>・各タスクにタスク名・期限・完了状態が表示される<br>・再アクセスしてもタスクが残っている |
| **MVP** | ✅ |

---

### 完了 / 未完了の切り替え

| 項目 | 内容 |
|---|---|
| **ID** | US-03 |
| **ストーリー** | ユーザーとして、タスクを完了済みにしたい。なぜなら、やり終えたことを記録して残りのタスクを把握したいから。 |
| **受け入れ条件** | ・各タスクにチェックボックスがある<br>・チェックをオンにすると完了状態になる<br>・チェックをオフにすると未完了状態に戻る |
| **MVP** | ✅ |

---

### タスクの削除

| 項目 | 内容 |
|---|---|
| **ID** | US-04 |
| **ストーリー** | ユーザーとして、不要なタスクを削除したい。なぜなら、リストをすっきり保ちたいから。 |
| **受け入れ条件** | ・各タスク行に削除ボタンがある<br>・削除ボタンを押すとリストから即時消える |
| **MVP** | ✅ |

---

### 期限の設定と確認

| 項目 | 内容 |
|---|---|
| **ID** | US-05 |
| **ストーリー** | ユーザーとして、タスクに期限を設定して確認したい。なぜなら、締め切りを忘れずに管理したいから。 |
| **受け入れ条件** | ・タスク追加時に期限（日付）を設定できる<br>・一覧に期限日が表示される<br>・期限は任意設定（未設定も可） |
| **MVP** | ✅ |

---

### タスクの検索

| 項目 | 内容 |
|---|---|
| **ID** | US-06 |
| **ストーリー** | ユーザーとして、キーワードでタスクを絞り込みたい。なぜなら、タスクが増えたときに目的のタスクをすぐ見つけたいから。 |
| **受け入れ条件** | ・検索欄にキーワードを入力するとリストがリアルタイムに絞り込まれる<br>・検索欄を空にすると全タスクが表示される |
| **MVP** | ✅ |

---

### データの永続保存

| 項目 | 内容 |
|---|---|
| **ID** | US-07 |
| **ストーリー** | ユーザーとして、ブラウザを閉じても次回アクセス時にタスクが残っていてほしい。なぜなら、毎回登録し直すのは手間だから。 |
| **受け入れ条件** | ・タスクは SQLite に保存される<br>・アプリを再起動・再アクセスしてもデータが保持される |
| **MVP** | ✅ |
